# Blog editor

After this branch is merged and deployed, the private editor lives at:

`https://rohanc.dev/admin`

## Writing a post

1. Sign in.
2. Choose **Post** and create a new document.
3. Add the title, summary, cover image, and article.
4. Drag images directly into the article when needed.
5. Save while drafting and press **Publish** when it is ready.

Published posts appear under Writing automatically. There are no Markdown files, Git commands, or portfolio deployments in the authoring workflow.

The project is already connected to Sanity project `0we3mwlb`. Authenticated CORS access is configured for `https://rohanc.dev` and `http://localhost:4173`.
